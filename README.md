# Agora

Agora is a small full-stack event management application that I am building incrementally as a project.

The initial goal is to allow an event organizer to create an event with a name and date, save it, and view it in an event list.

## Current Status

Project planning.

No application code has been implemented yet.

## Planned Stack

* React
* TypeScript
* Java
* Spring Boot
* PostgreSQL

This planned stack may change as the project develops.
